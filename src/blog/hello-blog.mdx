## What this enables

You can now add a new `.mdx` file under `src/blog/` with frontmatter like this:

```mdx
---
title: "My New Post"
description: "A short description for the blog list and meta tag."
pubDate: 2026-04-30
tags: ["research", "engineering"]
draft: false
titleColor: "text"
---

Your post content goes here.
```

Set `draft: true` when a post should stay hidden from the blog list and from generated pages.
